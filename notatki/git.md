git init: Tworzy nowe, puste repozytorium Gita w wybranym katalogu. Od tego momentu program zaczyna śledzić zmiany w plikach tego projektu.

git clone: Pobiera kopię istniejącego repozytorium ze zdalnego serwera na Twój komputer. Tworzy pełną lokalną wersję projektu wraz z całą jego historią.

git status: Pokazuje aktualny stan Twojego katalogu roboczego i poczekalni. Pozwala sprawdzić, które pliki zostały zmienione, dodane lub przygotowane do zapisu.

git add: Dodaje wybrane pliki lub zmiany do tzw. poczekalni (staging area). Przygotowuje je do tego, by stały się częścią kolejnego punktu zapisu.

git commit: Zapisuje przygotowane zmiany z poczekalni jako nową migawkę w historii projektu. Każdy taki zapis posiada opisujący go komunikat autorski.

git push: Wysyła Twoje lokalne zapisy (commity) na zdalny serwer, np. do GitHuba. Dzięki temu inni członkowie zespołu mają dostęp do Twoich najnowszych zmian.

git pull: Pobiera najnowsze zmiany ze zdalnego serwera i automatycznie łączy je z Twoim lokalnym kodem. Utrzymuje Twoją lokalną wersję projektu w pełnej aktualności.

git branch: Wyświetla listę istniejących gałęzi w projekcie lub pozwala utworzyć nową. Umożliwia bezpieczne rozwijanie nowych funkcji w izolacji od głównego kodu.
